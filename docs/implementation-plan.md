# 实施计划与验收标准

状态：首期 SDK/CLI 已实现，验证情况见 [验证记录](validation.md)。跨平台 CI、正式 npm 发布与账号配置尚未完成。以下保留阶段目标作为验收清单。

## M0：来源与工具链验证

- 固定两个上游仓库的 commit，阅读对应源码、许可证、算法来源及导出模板。
- 建立移植清单：来源路径、目标模块、复用方式、原版权、行为差异。
- 在隔离验证中确认 pnpm、Lerna、TS7、tsdown、Oxlint、Oxfmt、Vitest、Sharp 的稳定版本组合。
- 验证 TS7 类型检查、isolatedDeclarations 声明生成、workspace 导入和安装产物。
- 确定 Node 最低版本；检查暂定 npm scope、包名及 CLI 名称。

验收：最小样例完成 JS/声明构建和独立消费；记录准确版本与限制。没有验证前不宣称工具链兼容。

## M1：Monorepo 骨架

- 建立 core/node/cli 三包、workspace 协议、统一版本和根目录开发依赖。
- 提供 lint、format:check、typecheck、test、build、check:package 等根命令。
- 配置包出口、files 白名单、原生依赖 external 和发布 tarball 检查。
- 建立 GitHub Actions、贡献指南及上游声明记录方式。

验收：干净检出后冻结安装，构建与检查通过；core 的源码和产物不引入 Node/DOM/Sharp。仅有空测试通过不算功能完成。

## M2：最小可用闭环

- PNG 文件与字节输入 → RGBA → 单策略 MaxRects → 合成 → PNG + JSON Hash。
- Node pack 返回产物，writeOutput 显式写盘，CLI 调用同一 SDK。
- 建立代表性素材 fixture，包括正常、损坏、超大、重复名称输入。

验收：通过 npm tarball 安装后，SDK 与 CLI 均能生成图集；反向提取结果与原始像素一致；失败时不发布残缺结果。

## M3：首期能力完整

- 透明裁边、去重、90° 旋转、间距、画布边距、extrude。
- 自动/固定尺寸、POT、正方形、多页和稳定命名。
- JSON Array、Phaser 4 导出及自定义导出函数。
- JSON 配置和 Schema、错误码、统计、dry-run、机器可读报告。

验收：各能力组合的几何和像素验证通过；全透明、半透明边缘、单像素、中文路径均有用例；Phaser 示例真实加载，包含旋转和多页。

## M4：0.1.0 发布准备

- Linux/macOS/Windows 与最低/主要 LTS Node 版本验证。
- 干净环境安装 npm tarball，分别验证 SDK 类型和 CLI bin。
- README 快速开始、配置参考、错误说明、迁移差异、许可证及第三方声明齐全。
- 建立小中大素材集的性能基线，记录素材来源、硬件、版本、耗时、峰值内存、页数和利用率。
- 配置 Lerna 统一版本发布；优先采用 npm Trusted Publishing。

验收：全部必需检查通过，发布内容可审阅，版本和变更说明准确。首期交付本地与 CI 可用的 0.1.0；实际 npm 发布单独执行。

## 必需验证

| 主题     | 验证方式                                           |
| -------- | -------------------------------------------------- |
| 排布正确 | 无越界、无重叠、无丢失；包含扩展区域和间距         |
| 像素正确 | 按元数据提取、逆旋转与还原，对比预期像素           |
| 去重正确 | 哈希后二次比较，验证别名的源尺寸与裁边信息         |
| 确定性   | 打乱输入顺序、重复执行，对比图集模型与固定环境产物 |
| 导出可用 | JSON 解析、字段语义校验、Phaser 消费端加载         |
| CLI      | 真子进程、退出码、流分离、路径基准、输出失败恢复   |
| npm 包   | tarball 安装、exports/types/bin、许可证随包分发    |

上游差异测试只作为参照，不将上游行为当成唯一正确答案。优先测试公开接口和可观察产物，不为每个内部函数编写镜像测试。

## 后续版本

0.2 候选：更多格式、watch、按测量结果优化性能。GUI 在核心配置与结果模型稳定后启动。JPEG/WebP、模板兼容、云压缩、Worker、缓存等按实际需求逐项评估。

## 待验证事项

- 暂定包名和 scope 的可用性、实际发布账号。
- 最低 Node 版本及工具链补丁版本组合。
- Sharp 安装与编解码的跨平台差异。
- Phaser 多页及旋转导出的准确结构和消费版本。
- 上游 GUI 配置是否需要未来迁移工具。
- 许可证目前署名为 SpriteCrate contributors；正式发布前按作者意愿确认个人署名，保留各实际权利人的声明。
